# Safety notice - MiR1200 Pallet Jack Hold-to-run and brake test {% tag="safety_notice_mir1200_pallet_jack_hold_to_run_and_brake_test" %}

Two issues have been discovered that can affect the during manual operation and commissioning. Solutions to these issues require new parts, new software, and/or support from MiR. All customers will be contacted by MiR when new parts and software are available.

Issue #1: There could be a fault in the hold-to-run system that causes motion to continue even when the hold-to-run switch is released by the operator. If a person is in the path of the robot when this condition exists, serious injury or death can occur. This condition can only occur when using the tiller to control the robot manually.

Issue #2: Personnel external to MiR do not have the capability to perform a brake test. A brake test is required at the time of commissioning to confirm that the robot operates as expected in the installed environment. If braking performance is not confirmed, the robot could take longer to stop than expected for the factory settings for the personnel detection safeguarding. The Personnel detection safety function must be set to be appropriate for the conditions of use, otherwise the Personnel detection safety function may not detect an object and stop as designed. If this were to happen, serious injury or death can occur.

IMMEDIATE ACTION REQUIRED:

ISSUE #1 – HOLD TO RUN SYSTEM

*   Do not control manually using the tiller until the tiller assembly has been replaced.
    
*   If operators use the tiller prior to replacement of the tiller assembly, operators must be informed that motion may continue after release of the hold-to-run switches.
    
*   If this condition occurs, immediately press the safety stop button on the tiller and stop use of until the tiller assembly has been replaced.
    
*   When an updated tiller assembly is available, customers will be contacted to arrange replacement.

ISSUE #2 – BRAKE TEST DURING COMMISSIONING

*   Contact MiR to arrange a brake test. A brake test in the installed location is a requirement of commissioning and a MiR technician will be provided to perform the brake test.
    
*   When updated software is released that will enable an on-site brake test, customers will be informed and urged to update to the latest version of software.

{% notice type="warning" %}

Serious injury or death can result from uncontrolled motion caused by a fault in the hold to run system.

* Contact MiR to arrange for a replacement tiller assembly. Replacement tiller assemblies are expected to be available by June, 2025.

{% /notice %}

{% notice type="warning" %}

Serious injury or death can result if the safety system fields are not set to account for braking conditions at the installed site.

* Contact MiR to arrange for an on-site brake test.

* Upgrade the robot software when the update with brake test functionality is released. This software release is expected by June, 2025. All customers of affected MiR1200 Pallet Jack robots will be notified when the software is available.

{% /notice %}

To arrange for a replacement tiller assembly and / or an onsite brake test, please reach out to your local distributor or open a support ticket: https://mobile-industrial-robots.com/contacts.

An email confirmation of receipt of this safety notice is required. Send the email confirmation to safetynotices@mir-robots.com.
