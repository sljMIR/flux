Before performing maintenance of the robot:

1. Move the robot away from the production environment. Preferably to a dedicated service or maintenance area.

2. In the robot interface, go to **System > Settings > Wi-Fi**, and select **Disconnect** to ensure that the robot does not receive commands from MiR Fleet while maintenance is being performed. You will have to reconnect Wi-Fi to perform {% tagref "inspect_and_test_the_signal_lights" /%}

3. Turn off the robot and disconnect the battery as described in {% tagref "disconnecting_the_battery" /%}.

4. Lift the robot up onto support blocks on a work bench or equivalent for easier access. See {% tagref "lifting_the_robot" /%}.
