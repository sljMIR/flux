
1. Turn off the robot and disconnect the battery. This ensures that the only the mechanical brakes are being tested.

2. Try to move the robot left and right by hand:
   - If it does **not move**, the brakes are functional.
   - If it moves, one or both mechanical brakes are faulty. Contact MiR Technical Support

3. Turn on the robot.

4. Ensure the manual brake release is **not engaged** (turn counter-clockwise).

3. Try to move the robot left and right by hand:
   - If it does **not move**, the brakes are functional.
   - If it moves, there is a fault in the connection to the brakes. Contact MiR Technical Support

4. Engage the manual brake release (turn clockwise).

5. Try to move the robot again:
   - If it moves, the manual brake release control is functional.
   - If it does **not move**, contact MiR Technical Support.
