To connect to the robot web-interface, follow these steps:

1. Connect your device directly to the robot using an Ethernet cable, or connect an access point to the Ethernet port for a wireless connection.
2. If you are using an access point, connect your device to the access point. The MiR Access Point Wi-Fi has the following format: MiR\_3042XXXXX. Use the password shipped with the access point to connect.
3. In a browser, go to the address 192.168.12.20 and sign in.
