The robot is intended to be commissioned and used in indoor industrial environments where access for the public is restricted. It must be designed, commissioned, and integrated by a system manufacturer and according to the guidelines in {% tagref tag="commissioning" /%}. 

This is a prerequisite for safe usage. Guidelines outlined in this manual will not provide adequate risk reduction. A complete risk assessment is required.

The robot is equipped with safety-related features that are purposely designed for collaborative operation in a space not limited by perimeter safeguards, such as fixed guards or safety light curtains.

Any use or application deviating from intended use is deemed to be impermissible misuse—see {% tagref tag="forseeable_miuse" /%}.
