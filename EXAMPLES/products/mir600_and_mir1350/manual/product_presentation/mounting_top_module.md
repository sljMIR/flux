# Mounting a top module

The robot has four M10 holes for mounting top modules as shown in Figure 4.24. The tightening torque is 47 Nm. The mounting screws must have a length between 27–45 mm from the top of the top cover.

The robot also has four M12 lifting holes used for fixation of transportation eye-bolts.

The M12 lifting holes can also be used to mount top modules. If a top module is mounted using these holes, it is necessary to drill M12 lifting holes in the top module in order to lift the robot. Alternatively, the top module must be removed to access the M12 holes.
