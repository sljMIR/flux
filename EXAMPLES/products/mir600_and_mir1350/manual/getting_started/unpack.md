# Unpack the robot {% tag "unpack_the_robot" /%}

{% partial file="products/_manual_partials/packaging/text_store_packaging.md" /%}

To unpack the robot, follow these steps:

1. Place the box with the robot so that there is at least three meters of free space at the front or the back of the box.

2. Remove the screws that attach the walls of the box to the box lid and the base of the box. Use a T20 bit.

   {% image src="/images/mir600_1350/packaging/rtemove_box_screws.webp" alt="The screws are removed around the box. "  /%}

3. Remove the lid from the box, and remove the wooden lath beneath the lid. Use a T20 bit.

   {% image src="/images/mir600_1350/packaging/remove_lid.webp" alt="The lid is removed from the box"  /%}

4. Take the package with the printed documents and accessories out of the box.

   {% image src="/images/mir600_1350/packaging/take_out_box.webp" alt="The box with additional content is removed. "  /%}

5. Remove the pallet collars and the protective foam blocks.

   {% image src="/images/mir600_1350/packaging/remove_sides.webp" alt="The pallet collars are removed by pulling them up."  /%}

   {% image src="/images/mir600_1350/packaging/remove_padding.webp" alt="The padding is removed around the robot."  /%}

6. Cut the protective straps.

   {% image src="/images/mir600_1350/packaging/cut_straps.webp" alt="The straps around the robot are cut. "  /%}

7. For increased traction, you can add the nine supplied anti-slip pads to the top plate. Remove the protective foil from each pad to expose the adhesive side, and place the pads in the designated recesses in the top plate.

   {% image src="/images/mir600_1350/packaging/anti_slip.webp" alt="The anti-slip pieces are put on the robot. "  /%}

8. Place the lid of the box so that you can use it as a ramp. Align the lid so that it is flush with the base of the box.

   {% image src="/images/mir600_1350/packaging/place_ramp.webp" alt="The lid is placed as a ramp on the end of the pallet in front of the robot. "  /%}

9. Remove the wheel stop board from the pallet to let the robot drive on the ramp. Use a T20 bit.

   {% image src="/images/mir600_1350/packaging/remove_stop.webp" alt="The wheel stop screws are removed. "  /%}

It is optional if you want to apply the visibility stickers to the corners of the robot.

{% image src="/images/mir600_1350/packaging/stickers.webp" alt="Visibility sticker on one of the robot's corners."  /%}
