## Front compartment {% tag "front_compartment" /%}

1. Unscrew the two screws holding the front cover. Use a T30 screwdriver.

    {% image id="c9d483d2-3ad2-4855-9de3-256715a2f939" alt="Unscrewing front cover" /%}

2. Loosen the bottom corners one at the time by pulling out each corner.

    {% image id="56ff82f0-889e-4aef-b010-3be44f13f1aa" alt="Loosening bottom corners" /%}

3. Loosen the top corners one at the time by pulling each corner down, and then out.

    {% image id="3bc0d8e5-3432-4117-8233-43eff73f53db" alt="Loosening top corners" /%}

4. Pull off the cover.

    {% image id="ef78a818-42bc-4c46-8396-ab0d1a10f829" alt="Removing front cover" /%}

## Rear compartment{% tag "rear_compartment" /%}

1. Push the two white buttons on the rear cover at the same time.

    {% image id="d3333943-ef38-4534-98f6-1b9436b3b909" alt="Pressing rear buttons" /%}

2. Loosen the bottom corners one at the time by pulling out each corner.

    {% image id="1cc06cb1-8822-4c5d-93f1-7eef3978018a" alt="Loosening rear bottom corners" /%}

3. Loosen the top corners one at the time by pulling each corner down, and then out.

    {% image id="31ab0280-6499-4c91-8956-c4095f277082" alt="Loosening rear top corners" /%}

4. Pull off the cover.

    {% image id="5cfac09e-ba63-49b7-835d-ed0424d65363" alt="Removing rear cover" /%}

## Side compartments

1. Open the front and rear compartments first see {% tagref "front_compartment" /%} and {% tagref "rear_compartment" /%}.

2. Turn the two screws counterclockwise. Use a T30 bit.

    {% image id="ba020c7d-f24b-4aa3-b952-f2655fbcb946" alt="Unscrewing side compartment" /%}

3. Loosen the bottom corners one at the time by pulling out each corner.

    {% image id="d5c76385-5114-4820-b707-db8fbcbcb0e2" alt="Loosening side bottom corners" /%}

4. Pull off the cover.

    {% image id="c484134d-bc74-415c-8f55-6d9e646b6424" alt="Removing side cover" /%}

## Top compartments

1. Unscrew and remove the antenna from the top cover.

    {% image id="8f0f045f-125d-4391-bfc8-53fdfcfa7673" alt="Unscrewing antenna" /%}

2. Unscrew the nut from the antenna connector, and push the antenna cable free of the cover. Use an 8 mm wrench.

    {% image id="6f01cef1-94e3-47b7-9e20-9b55cd163dc7" alt="Unscrewing antenna bolt" /%}

3. Unscrew the four screws and remove the cover. Use a T10 bit.

    {% image id="3384fb59-e4d1-46a9-9eb7-a9300d75d775" alt="Unscrewing top compartment" /%}
