## Power interface compartment

The power interface cover is held in place by a magnet. Pull open the cover to access the compartment.

{% image src="/images/mir1200_pallet_jack/access/battery_connection_cover.webp" alt="The power interface cover being removed. "  /%}

## Front compartment

1.  Remove the four screws on the front covers. Use a T30 bit.

    {% image src="/images/mir1200_pallet_jack/access/middle_compartment_screws.webp" alt="The screws on the front covers being removed. " %}

2.  Pull open the covers to access the front compartment.

    {% image src="/images/mir1200_pallet_jack/access/middle_compartment_hatches.webp" alt="The front covers being opened." %}

3.  Turn the screws in the electronics box cover using the key delivered with the robot. Remove the electronics box cover.

    {% image src="/images/mir1200_pallet_jack/access/front_compartment_screws.webp" alt="The screws in the electronics box cover. " %}

## Rear compartments

1.  Remove the two top screws on the rear covers, and loosen the bottom screws. Use a T30 bit.

    {% image src="/images/mir1200_pallet_jack/access/right_rear_cover.webp" alt="The screws in the rear right cover being loosened at the bottom and removed at the top." %}

2.  Remove the rear covers.

    {% image src="/images/mir1200_pallet_jack/access/rear_compartment_off.webp" alt "The rear cover being removed." %}

## Top compartment

1.  Remove the four screws on the front covers. Use a T30 bit.

    {% image src="/images/mir1200_pallet_jack/access/middle_compartment_screws.webp" alt="The screws on the front covers being removed. " %}

2.  Pull open the covers.

    {% image src="/images/mir1200_pallet_jack/access/middle_compartment_hatches.webp" alt="The front covers being opened." %}

3.  Push open the top cover. The top cover lock pin will snap into place when the cover reaches its open position. To close the top cover again, pull the top cover lock pin outwards while pushing the top cover slightly upwards to remove downward pressure from the pin.

    {% image src="/images/mir1200_pallet_jack/access/top_compartment_lock_pin.webp" alt="The location of the top cover lock pin." %}

## Halo

1.  Remove the eight screws on the rear Halo cover. Use a T30 bit.

    {% image src="/images/mir1200_pallet_jack/access/mast_compartment_rear.webp" alt="The screws being removed from the rear Halo cover." %}

2.  Remove the rear Halo cover.

    {% image src="/images/mir1200_pallet_jack/access/mast_compartment_rear_off.webp" alt="The Halo cover being removed. " %}

3.  Remove the two screws on the front Halo cover. Use a T30 bit.

    {% image src="/images/mir1200_pallet_jack/access/mast_compartment_front.webp" alt="The screws being removed from the front Halo cover." %}

4.  Remove the front Halo cover.

    {% image src="/images/mir1200_pallet_jack/access/mast_compartment_front_off.webp" alt="The front Halo cover being removed." %}

## Bottom compartment

1.  Remove the four screws on the status light cover. Use a T45 bit.

  {% image src="/images/mir1200_pallet_jack/access/bottom_cover_screws.webp" alt="The screws being removed from the bottom cover." %}

2.  Open the electronics box and unplug the status light cable in order to be able to remove the cover. The yellow lock on the connector must be pulled outwards before the cable can be disconnected.

    {% image src="/images/mir1200_pallet_jack/lights/status_light_connector.webp" alt="Location of the status light connector." %}

3.  Remove the status light cover by sliding it outwards while lifting slightly.

    {% image src="/images/mir1200_pallet_jack/access/bottom_cover_off.webp" alt="The bottom cover being removed." %}

## Footguard

1.  Remove the two screws on the foot guard, one on each side. Use an 8 mm hex bit.

    {% image src="/images/mir1200_pallet_jack/access/bumper_bolts.webp" alt="The location of the foot guard screws." %}

2.  Loosen the two bolts in the front of the robot. Use an 8 mm hex bit.

    {% image src="/images/mir1200_pallet_jack/access/bumper_loosen_hanger_bolts.webp" alt="The location of the foot guard hanger bolts." %}

3.  Cut all cable ties that hold the power cable. When reassembling, apply new cable ties to hold the cable.

    {% image src="/images/mir1200_pallet_jack/access/bumper_compartment_zip.webp" alt="Identification of the cable ties on the power cable you need to cut." %}

4.  Raise the foot guard while pulling it out to get the hooks out of the bolts. Lay it to the side where the power cable is attached. Be careful not to damage the cable.

    {% image src="/images/mir1200_pallet_jack/access/bumper_compartment_to_the_side.webp" alt="The foot guard moved to the side of the robot." %}
