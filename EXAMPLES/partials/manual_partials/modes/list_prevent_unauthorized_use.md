To prevent unauthorized users from accessing the robot:

* Keep passwords to connect to the robot interface and the robot components strictly confidential. Assign each robot user with their own user in the interface and make sure they each have a unique username and password.
* Follow the cybersecurity guidelines in {% tagref "evaluate_cybersecurity" /%}
* Always remove the Operating mode key from the robot when it is operating.
